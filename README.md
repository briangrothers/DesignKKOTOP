# DesignKKOTOP
Приложение для дизайна и интерьера созданное для дипломной работы 

# О проекте 

DesignKKOTOP - это приложение с открытым исходным кодом для создания планировок помещений и расстановки мебели. Разработано для дизайнеров, архитекторов и обычных пользователей кто хочет визуализировать интерьер своей мечты.

# Основной функционал

    Построение стен с регулируемой толщиной и цветом
    Двери и окна
    Мебель - Каталог из 100+ предметов с категориями
    Полы - 12 типов покрытий с различными текстурами
    Сохранение - Проекты сохраняются в JSON формате


# Интерактивность:

    Перетаскивание объектов мышью
    Поворот мебели (клавиша R)
    Прилипание к сетке (шаг 0.5м)
    Прилипание к стенам
    Подсветка при наведени
    Предпросмотр при размещении
    Контекстное меню правой кнопкой мыши

# Категории мебели:

# Первые шаги

    1. Выберите режим "Построить стены"
    2. Кликните для начала стены
    3. Кликните еще раз для завершения
    4. Создайте замкнутый контур
    5. Добавьте двери и окна
    6. Выберите мебель из каталога
    7. Разместите мебель кликом
